# SineLume — Official Android Releases

Repositori distribusi publik resmi untuk APK Android **SineLume** (*streaming film, serial TV, Korean Drama, dan anime dengan Media3 ExoPlayer, PiP, koleksi watchlist, dan dukungan multi-subtitle*).

> Repositori ini hanya menyediakan file `.apk` rilis resmi untuk pembaruan aplikasi (*in-app update*) dan pemasangan langsung.

---

## Unduh Versi Terbaru

👉 **[Unduh SineLume Terbaru (GitHub Releases)](https://github.com/AffanShz/Sinelume-Releases/releases/latest)**

### Cara Pasang & Update
1. Buka tautan **[Latest Release](https://github.com/AffanShz/Sinelume-Releases/releases/latest)** dan unduh file `sinelume-v*.apk`.
2. Jika menginstal dari APK luar Play Store untuk pertama kali, aktifkan izin **Install unknown apps** untuk browser Anda.
3. Apabila muncul peringatan Google Play Protect *"App blocked to protect your device"* karena developer independen, ketuk **More details → Install anyway** (rilis ditandatangani secara konsisten oleh keystore SineLume agar update versi berikutnya menimpa instalasi lama tanpa menghapus data/riwayat tontonan).
4. Setelah terpasang, gunakan **Pengaturan → Pembaruan Aplikasi → Cek Update** atau pasang **Obtainium** dengan URL `https://github.com/AffanShz/Sinelume-Releases` untuk pembaruan otomatis.

---

## Persyaratan Awal Penggunaan

1. Buka aplikasi **SineLume** di Android (Android 8.0 / API 26 atau lebih baru).
2. Masukkan **TMDB API Read Access Token** (`eyJ...`) milik Anda — panduan langkah demi langkah tersedia langsung di layar awal aplikasi.
3. Opsional: atur bahasa subtitle default, gaya latar subtitle, atau API key Wyzie / SubDL pribadi di menu **Pengaturan**.
